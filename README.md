**פרויקט מסכם בהנדסת תוכנה - 5 יח"ל**
פיצ'רים קיימים:
- המשחק עצמו: גריד של משבצות בגודל משתנה בהתאם לרמת הקושי
- שמירת היסטוריית משחקים והצגתה ברשימה
- רשימת שיאים אישיים והצגתם בטבלת שיאים עבור כל רמת קושי
- פורטל פרופיל אישי ואפשרות ליצור שם שיופיע בטבלת השיאים
- מסך סטטיסטיקות על המשתמש והמשחקים שלו
- מערכת נקודות
- חנות אביזרים ושדרוגים
- אינוונטורי: אחסון ושימוש האייטמים
- מערכת הישגים - אצ'יומנטים
- מערכת סאונד: פיצוץ במקרה של הפסד
- ספלאש סקרין מותאם אישית
- מערכת משתמשים: רישום לפי מייל וסיסמה - מסך להרשמה ומסך לכניסה
- אופציה לשחק בתור אורח
- מערכת חברים - אופציה להוסיף חברים ולראות את הניקוד שלהם, לשלוח בקשות חברות - לאשר ולדחות בקשות
- מסך חוקים
- מערכת התראות - נוטיפיקציות
- הפרויקט בעיצוב אישי (פיקסל ארט ופלטת צבעים מותאמת)
- אנימציות לחיצה על כפתורים
- מסכי פופ-אפ לבחירת רמת קושי והתראה על ניצחון / הפסד
- מסכי טעינה בין מסכים
- שירות הודעות: שיתוף תוצאות משחק דרך מייל / הודעות / ווטסאפ...
- התראות יומיות: כל יום ב-19:00 בערב המשחק ישלח התראה לשחק
- סרביס של מוזיקת רקע ופיצוצים
- מסך הגדרות עם אפשרות לכבות את המוזיקה ואת ההתראות היומיות
